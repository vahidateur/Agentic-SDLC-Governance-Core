# Changelog

All notable public releases of the Agentic SDLC Governance Core are recorded here.

## [1.0.0] — 2026-07-24

### Added

- Initial documentation-only public governance core handoff.
- Fail-closed, no-inference, immutable-authority, provenance, ownership, evidence, blocking, concurrency, identity, and governance-record contracts.
- Stable Work Package Identity plus unique, non-reusable Attempt Identity for actual execution attempts.
- Public vocabulary for Run Identity, Evidence Artifact, Decision Record, `HUMAN_DECISION_REQUIRED`, and the Implementation-entry gate.
- Requirements, architecture handoff, verification matrix, schemas, review templates, examples, and markdown validation workflow.

### Scope boundary

No application code, dependencies, runtime integration, persistence, deployment, UI, provider, model, or technology-specific implementation is included.
